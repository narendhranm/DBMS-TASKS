# Task 4 – Order Management System

## Objective
Manage customer orders and order line items, including order date, quantity, product price, and total amount.

## Features
- `Orders` and `Order_Details` tables.
- Customer order insertion and modification.
- Multiple products per order.
- Automatic line-item subtotal.
- Order total calculation.
- Customer order-history retrieval.

## Files
- `order_management.sql` – schema and required order queries.

> Note: The final `Customer` table from Task 1 is referenced by `customer_id` and should be added to the shared database before enabling the order insert examples.
