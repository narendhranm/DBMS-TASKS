# Task 3 – Seller and Inventory Management System

## Objective
Manage sellers, seller-product relationships, stock quantities, and product availability.

## Features
- Seller and Inventory tables.
- Primary and foreign key relationships.
- Seller-product-stock mapping.
- Available/unavailable product tracking.
- Inventory reporting.

## Files
- `seller_inventory.sql` – schema, relationship query, availability update, and inventory report.
