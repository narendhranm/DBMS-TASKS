# Task-VIII — Database Relationship Analysis using Joins

## Objective
To analyze relationships between customers, products, orders, order details, and payments using SQL JOIN operations.

## Requirements Covered
1. Combine Customer, Product, Order, and Payment tables.
2. Implement INNER JOIN, LEFT JOIN, and RIGHT JOIN.
3. Retrieve complete order details.
4. Display customer purchase history.
5. Generate multi-table reports.

## Tables Used
- Customer
- Orders
- Order_Details
- Product
- Category
- Payment

## Key Concepts
- INNER JOIN returns matching records.
- LEFT JOIN keeps every row from the left table.
- RIGHT JOIN keeps every row from the right table.
- Multi-table joins connect Customer → Orders → Order_Details → Product → Category and Orders → Payment.

## How to Execute
1. Run Tasks 1–6 in order to create the database and tables.
2. Run Task 7 for the earlier query demonstrations if required.
3. Execute `task8_joins.sql` using MySQL Workbench or another MySQL client.
4. Review each numbered query and its result.

## Expected Outcome
The task produces complete order information, customer purchase history, payment details, product/category information, and multi-table relationship reports.
