# Task 1 – Requirement Analysis and Customer Database Module

## Objective
Analyze the E-Commerce Order Management System requirements and define the customer database module.

## Scope
- Identify business requirements.
- Identify customer information required by the system.
- Define functional and non-functional requirements.
- Prepare the foundation for the customer database.

## Customer Module
The customer module stores customer identity and contact information and supports customer registration, retrieval, update, and order-history relationships.

## Core Data
- Customer ID
- Customer name
- Email
- Phone
- Address

## Functional Requirements
1. Add a customer.
2. View customer details.
3. Update customer details.
4. Delete a customer when permitted.
5. Retrieve a customer's order history.

## Expected Outcome
A clear requirement specification that can be used to design the remaining database modules.
