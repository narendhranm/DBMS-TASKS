# Task-X — Advanced SQL Query System

## Objective
To implement advanced SQL techniques using subqueries, nested queries, correlated subqueries, and multi-table business analysis.

## Requirements Covered
1. Implement subqueries and nested queries.
2. Find products above average price.
3. Identify customers with maximum purchases.
4. Generate complex business queries.
5. Prepare an advanced SQL report.

## Tables Used
- Customer
- Category
- Product
- Orders
- Order_Details
- Payment
- Inventory

## Advanced Concepts
- Scalar subqueries
- IN and NOT IN subqueries
- EXISTS and NOT EXISTS
- Correlated subqueries
- Nested aggregate queries
- Common table expressions
- Multi-table business reports

## How to Execute
1. Run Tasks 1–6 first.
2. Execute `task10_advanced_queries.sql` using MySQL Workbench.
3. Review the result of each query.

## Expected Outcome
The task identifies products priced above the average, highest-spending customers, products with above-average sales, customers with repeated purchases, and other advanced business insights.
